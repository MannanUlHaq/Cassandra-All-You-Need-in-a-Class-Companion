# Cassandra-All-You-Need-in-a-Class-Companion

Cassandra is a multimodal AI-powered classroom assistant that helps students focus on learning instead of taking notes. The system automatically captures lecture audio, presentation slides, and handwritten whiteboard content, then combines them to generate well-structured study notes.

The platform uses Faster-Whisper for speech-to-text transcription, OCR and computer vision models to extract text, tables, and mathematical equations from lecture slides, and Retrieval-Augmented Generation (RAG) to enrich notes using reference textbooks. It also aligns spoken explanations with visual content to produce accurate and comprehensive lecture summaries.

In addition, Cassandra includes an AI tutor that allows students to ask questions about lecture content and receive context-aware answers. The project demonstrates the integration of Large Language Models (LLMs), computer vision, speech processing, and multimodal AI into a single educational platform.
